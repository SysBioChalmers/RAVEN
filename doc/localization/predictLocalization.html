predictLocalization

PURPOSE

predictLocalization Assign reactions to compartments using localization predictors.

SYNOPSIS

function [outModel, geneLocalization, transportStruct, scores,removedRxns] = predictLocalization(model, GSS,defaultCompartment, varargin)

DESCRIPTION 

 predictLocalization  Assign reactions to compartments using localization predictors.

 Tries to assign reactions to compartments in a manner that is in
 agreement with localization predictors while at the same time maintaining
 connectivity.

 Parameters
 ----------
 model : struct
     a model structure. If the model contains several compartments they
     will be merged.
 GSS : struct
     a gene scoring structure as from parseScores.
 defaultCompartment : char
     transport reactions are expressed as diffusion between the
     defaultCompartment and the others. This is usually the cytosol. The
     default compartment must have a match in GSS.

 Name-Value Arguments
 --------------------
 transportCost : double
     the cost for including a transport reaction. If this is a scalar then
     the same cost is used for all metabolites. It can also be a vector of
     costs with the same dimension as model.mets. Negative costs encourage
     transport of the metabolite (default 0.5).
 maxTime : double
     maximum optimization time in minutes (default 15).
 plotResults : logical
     true if the results should be plotted during the optimization
     (default false).

 Returns
 -------
 outModel : struct
     the resulting model structure.
 geneLocalization : struct
     structure with the genes and their resulting localization.
 transportStruct : struct
     structure with the transport reactions that had to be inferred and
     between which compartments.
 scores : struct
     structure that contains the total score history together with the
     score based on gene localization and the score based on included
     transport reactions.
 removedRxns : cell
     cell array with the reaction ids that had to be removed to have a
     connected input model.

 Notes
 -----
 This function requires that the starting network is connected when it is
 in one compartment. Reactions that are unconnected are removed and saved
 in removedRxns. Try running fillGaps to have a more connected input model
 if there are many such reactions. The input model should also not include
 any exchange, demand or sink reactions, otherwise this function would not
 provide any results.

 In the final model all metabolites are produced in at least one reaction.
 This does not guarantee a fully functional model since there can be
 internal loops. Transport reactions are only included as passive diffusion
 (A <=> B).

 The score of a model is the sum of scores for all genes in their assigned
 compartment minus the cost of all transport reactions that had to be
 included. A gene can only be assigned to one compartment. This is a
 simplification to keep the problem size down. The problem is solved using
 simulated annealing.

 Examples
 --------
     [outModel, geneLocalization, transportStruct, scores, removedRxns] = ...
         predictLocalization(model, GSS, defaultCompartment, ...
             transportCost, maxTime, plotResults);

0521                         %two transport reactions, going via the default

0803 function [S, g2c]=moveGene(S,model,g2c,geneToMove,toComp,nRxns,nMets)

0806 g2c(geneToMove,:)=false;
0807 g2c(geneToMove,toComp)=true;

0831 %Finds which metabolites are unconnected, in the sense that they are never
0832 %a product or only a product in a reversible reaction where one reactant is
0833 %only a product in the opposite direction of that reaction. This function
0834 %ignores exchange metabolites. Returns a vector of metabolite indexes.
0835 %metsToCheck is an array of metabolite indexes to check for connectivity.
0836 %If not supplied then all metabolites are checked
0837 function unconnected=findUnconnected(S,nEM,metsToCheck)
0838 if nargin>2
0839     %Do this by deleting everything from the network that is not in
0840     %metsToCheck and that is not exchange metabolites
0841     I=false(size(S,1),1);
0842     I(1:nEM)=true;
0843     I(metsToCheck)=true;
0844     S=S(I,:);
0845 end
0846 
0847 em=false(size(S,1),1);
0848 em(1:nEM)=true;
0849 
0850 %Construct a matrix in which the reversible reactions are inverted
0851 I=sum(S>2,1) | sum(S>2,1);
0852 revS=S;
0853 revS(:,I)=revS(:,I)*-1;
0854 
0855 %First calculate the ones that are ok
0856 %Produced in 2 rxns, is exchange, is not used at all, is produced in
0857 %non-reversible, involved in more than 1 reversible reactions
0858 connected=sum(S>0,2)>1 | em | sum(S~=0,2)==0 | sum(S(:,~I)>0,2)>0 | sum(S(:,I)~=0,2)>1;
0859 
0860 %Then get the ones that are unconnected because they are never produced
0861 unconnected=sum(S>0 | revS>0,2)==0 & connected==false;
0862 
0863 %Then get the ones that are potentially unconnected
0864 maybeUnconnected=~connected & ~unconnected;
0865 %maybeUnconnected=find(maybeUnconnectedS);
0866 
0867 %The metabolites in maybeUnconnected are involved in one reversible
0868 %reaction and not produced in any other reaction. This means that the
0869 %reactions which have at least one met in maybeUnconnected as reactant and
0870 %one as product are unconnected. The metabolites in maybeUnconnected that
0871 %are present in those reactions are then dead ends
0872 deadRxns=any(S(maybeUnconnected,:)>0) & any(S(maybeUnconnected,:)<0);
0873 
0874 %Get the mets involved in any of those reactions
0875 problematic=any(S(:,deadRxns)~=0,2);
0876 
0877 %If any of these are in the maybeUnconnected list then the metabolite is
0878 %unconnected
0879 unconnected(problematic & maybeUnconnected)=true;
0880 
0881 %Map back to metsToCheck
0882 if nargin>2
0883     unconnected=metsToCheck(unconnected(nEM+1:end));
0884 else
0885     unconnected=find(unconnected);
0886 end
0887 end

0889 %Given a set of unconnected metabolites, this function tries to move each
0890 %gene that could connect any of them, calculates the number of newly
0891 %connected metabolites minus the number of newly disconnected metabolites.
0892 %As some metabolites are very connected, only 25 genes are checked. Genes
0893 %that have a low score in their current compartment are more likely to be
0894 %moved
0895 function [geneIndex, moveTo, deltaConnected, deltaScore]=selectGenes(S,nEM,nMets,nER,nRxns,model,unconnected,g2c,GSS)
0896 %If moveTo is 0 then the gene cannot connect any of the metabolites
0897 moveTo=zeros(numel(model.genes),1);
0898 deltaConnected=zeros(numel(model.genes),1);
0899 
0900 %First get where the metabolites are now
0901 nComps=size(g2c,2);
0902 comps=ceil((unconnected-nEM)/((size(S,1)-nEM)/nComps));
0903 
0904 %Find the corresponding metabolite indexes if they all were in the default
0905 %compartment
0906 dcIndexes=unique(unconnected-(comps-1)*nMets);
0907 
0908 %Then find them if they were in any other compartment
0909 allIndexes=dcIndexes;
0910 for i=1:nComps-1
0911     allIndexes=[allIndexes;dcIndexes+nMets*i];
0912 end
0913 
0914 %Also check which reversible reactions that could be used
0915 I=sum(S>2,1) | sum(S>2,1);
0916 revS=S;
0917 revS(:,I)=revS(:,I)*-1;
0918 
0919 %Find all reactions that could make any of the unconnected metabolites in
0920 %some other compartment
0921 newMets=setdiff(allIndexes,unconnected);
0922 [~, potential]=find(S(newMets,:)>0 | revS(newMets,:)>0);
0923 potential(potential<=nER | potential>nER+nRxns*nComps)=[]; %No exchange rxns or transport rxns
0924 
0925 %Map J to the real metabolic reactions in model
0926 rxnComps=ceil((potential-nER)/(nRxns));
0927 
0928 %Find the corresponding reaction indexes if they all were in the default
0929 %compartment
0930 dcRxnIndexes=potential-(rxnComps-1)*nRxns;
0931 
0932 %Get the genes for those reactions
0933 genes=find(sum(model.rxnGeneMat(dcRxnIndexes,:)>0,1));
0934 
0935 %For some cases there can be very many reactions to connect something. This
0936 %is in particular true in the beginning of the optimization if, say, ATP is
0937 %unconnected. Therefore limit the number of genes to be checked to 25.
0938 %Weigh so that genes with bad scores in their current compartment are more
0939 %likely to be moved.
0940 
0941 %Get scores for these genes
0942 [~, J]=find(g2c(genes,:));
0943 
0944 %Add a small weight so that genes in their best compartment could be moved
0945 %as well
0946 geneScores=GSS.scores(sub2ind(size(g2c),genes(:),J));
0947 modGeneScores=1.1-geneScores;
0948 if numel(genes)>25
0949     rGenes=genes(randsample(numel(genes),min(numel(genes),25),true,modGeneScores));
0950     
0951     %The sampling with weights could give duplicates
0952     rGenes=unique(rGenes);
0953     
0954     %Reorder the geneScores to match
0955     [~, I]=ismember(rGenes,genes);
0956     geneScores=geneScores(I);
0957     genes=rGenes;
0958 end
0959 for i=1:numel(genes)
0960     %Since one gene is moved at a time, only metabolites involved in any of
0961     %the reactions for that gene can become unconnected. This helps to
0962     %speed up the algorithm. First get all involved reactions in the
0963     %default compartment
0964     rxns=find(model.rxnGeneMat(:,genes(i)));
0965     
0966     %Then get their mets
0967     mets=find(sum(model.S(:,rxns)~=0,2)>0);
0968     
0969     %Then get their indexes in all compartments
0970     allIndexes=mets;
0971     for j=1:nComps-1
0972         allIndexes=[allIndexes;mets+nMets*j];
0973     end
0974     
0975     %Check which of the unconnected metabolites that these reactions
0976     %correspond to. This could have been done earlier, but it is fast. The
0977     %reversibility check is skipped because it is unlikely to be an issue
0978     %here. Worst case is that the gene is tested once to much
0979     [I, ~]=find(model.S(:,rxns));
0980     moveToComps=unique(comps(ismember(dcIndexes,I)));
0981     
0982     %Try to move the gene to each of the compartments
0983     bestMove=-inf;
0984     bestComp=[];
0985     for j=1:numel(moveToComps)
0986         newS=moveGene(S,model,g2c,genes(i),moveToComps(j),nRxns,nMets);
0987         
0988         %Check how many metabolites that are unconnected after moving the
0989         %gene
0990         dConnected=numel(unconnected)-numel(findUnconnected(newS,nEM,[allIndexes;unconnected]));
0991         if dConnected>bestMove
0992             bestMove=dConnected;
0993             bestComp=moveToComps(j);
0994         end
0995     end
0996     
0997     %Add the difference in connectivity and where the genes should be moved
0998     moveTo(genes(i))=bestComp;
0999     deltaConnected(genes(i))=bestMove;
1000 end
1001 
1002 %Finish up
1003 geneIndex=genes(:);
1004 moveTo=moveTo(geneIndex);
1005 deltaConnected=deltaConnected(geneIndex);
1006 deltaScore=GSS.scores(sub2ind(size(g2c),geneIndex(:),moveTo))-geneScores;
1007 end

1045 %RANDSAMPLE Random sample, with or without replacement.
1046 %   Y = RANDSAMPLE(N,K) returns Y as a vector of K values sampled uniformly
1047 %   at random, without replacement, from the integers 1:N.
1048 %
1049 %   Y = RANDSAMPLE(POPULATION,K) returns K values sampled uniformly at
1050 %   random, without replacement, from the values in the vector POPULATION.
1051 %
1052 %   Y = RANDSAMPLE(...,REPLACE) returns a sample taken with replacement if
1053 %   REPLACE is true, or without replacement if REPLACE is false (the default).
1054 %
1055 %   Y = RANDSAMPLE(...,true,W) returns a weighted sample, using positive
1056 %   weights W, taken with replacement.  W is often a vector of probabilities.
1057 %   This function does not support weighted sampling without replacement.
1058 %
1059 %   Example:  Generate a random sequence of the characters ACGT, with
1060 %   replacement, according to specified probabilities.
1061 %
1062 %      R = randsample("ACGT",48,true,[0.15 0.35 0.35 0.15])
1063 %
1064 %   See also RAND, RANDPERM.

1092         else

1114         if isempty(population)

1116         'K must be less than or equal to N for sampling without replacement.');
1117         else
1118             error('stats:randsample:SampleTooLarge',...
1119                   'K must be less than or equal to the population size.');
1120         end
1121     end
1122 
1123     if isempty(w)
1124         % If the sample is a sizeable fraction of the population,
1125         % just randomize the whole population (which involves a full
1126         % sort of n random values), and take the first k.
1127         if 4*k > n
1128             rp = randperm(n);
1129             y = rp(1:k);
1130 
1131         % If the sample is a small fraction of the population, a full sort
1132         % is wasteful.  Repeatedly sample with replacement until there are
1133         % k unique values.
1134         else
1135             x = zeros(1,n); % flags
1136             sumx = 0;
1137             while sumx < k
1138                 x(ceil(n * rand(1,k-sumx))) = 1; % sample w/replacement
1139                 sumx = sum(x); % count how many unique elements so far
1140             end
1141             y = find(x > 0);
1142             y = y(randperm(k));
1143         end
1144     else

1146               'Weighted sampling without replacement is not supported.');
