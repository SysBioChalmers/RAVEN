sampleACHR

PURPOSE

sampleACHR Artificially Centered Hit-and-Run flux sampling.

SYNOPSIS

function solutions = sampleACHR(model, nSamples, thinning, warmup, seed)

DESCRIPTION 

 sampleACHR  Artificially Centered Hit-and-Run flux sampling.

 Draws nSamples flux vectors approximately uniformly from the flux polytope
 {v : S*v = 0, lb <= v <= ub}, using the ACHR algorithm (Kaufman & Smith 1998).
 No rounding is performed, so on strongly elongated polytopes (e.g.
 enzyme-constrained models) mixing is slower than sampleCHRR; prefer CHRR there.

 Parameters
 ----------
 model : struct
     a RAVEN model structure.
 nSamples : double
     number of flux vectors to return (default 1000).
 thinning : double
     Markov-chain steps between recorded samples (default 100).
 warmup : double
     nPoints-by-nRxns warmup vertices (default: generated by sampleWarmupPoints).
 seed : double
     random seed for reproducibility (default: current RNG state).

 Returns
 -------
 solutions : double
     nRxns-by-nSamples matrix of sampled flux distributions.

 See also
 --------
 randomSampling, sampleCHRR, sampleWarmupPoints
