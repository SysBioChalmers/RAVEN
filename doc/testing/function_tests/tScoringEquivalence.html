0002 % tScoringEquivalence  Can scoreComplexModel stand in for scoreModel?
0003 %
0004 %   scoreModel and scoreComplexModel both turn HPA and/or array data into a
0005 %   score per reaction, but they are separate implementations: scoreModel
0006 %   reduces over the genes in rxnGeneMat, scoreComplexModel evaluates the
0007 %   grRule with a configurable operator for AND and for OR.
0008 %
0009 %   The tests below establish where the two agree and where they cannot be
0010 %   made to agree by choice of options. The Matches* tests pin the settings
0011 %   under which scoreComplexModel reproduces scoreModel; the Diverges* tests
0012 %   pin the behaviours that a replacement would have to account for, and are
0013 %   expected to fail if either function is changed to close the gap.
0014 %
0015 %   Agreement requires isozymeScoring = complexScoring = 'max', which makes
0016 %   every grRule collapse to the maximum over its genes, i.e. what
0017 %   scoreModel computes with multipleGeneScoring = 'best'.
