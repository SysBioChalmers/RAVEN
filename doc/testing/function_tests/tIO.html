0082             % rxnDeltaG/metDeltaG round-trip through a <p>deltaG: VALUE</p>
0083             % notes entry -- the same key and format raven-toolbox reads
0084             % and writes, so either toolbox's SBML file is a complete
0085             % round trip for the other (RAVEN#724). An untouched reaction
0086             % or metabolite stays NaN, and the field is omitted entirely
0087             % if nothing in the model has a value. Values are the kind of
0088             % magnitude a real thermodynamic estimate has, not contrived
0089             % high-precision ones: num2str's default precision (no digits
0090             % argument) is exact for these, same as Confidence Level.
0091             m = testCase.model;
0092             m.rxnDeltaG = NaN(numel(m.rxns), 1);
0093             m.rxnDeltaG(1) = -8.7;
0094             m.metDeltaG = NaN(numel(m.mets), 1);
