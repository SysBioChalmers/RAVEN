0453             % e[s] takes part only in R7 and R8. With both gone from the

0456             % reference. That requirement is carried in b, and simplifyModel
0457             % must leave the metabolite in place: without its row the MILP
0458             % solves a problem that no longer asks for e[s], and reports the

0468             % e[s] reachable.

0473             tModel = setTaskBounds(mTemp);

0476             testCase.assertEmpty(sol.x, 'the task must start out infeasible');

0479                 'false,true,tmpRxnScores,struct(),false);']);
