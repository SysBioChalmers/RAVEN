0002 % RavenTestCase  Shared base class for the RAVEN function test suite.
0003 %
0004 %   Provides, once per test class:
0005 %     - ravenRoot : the RAVEN installation root.
0006 %     - model     : a small E. coli textbook model in RAVEN format, reloaded
