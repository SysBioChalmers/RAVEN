0004 % A single progress-reporting API used across RAVEN. The rendering backend
0005 % is selected automatically so that the same call works on an interactive
0006 % desktop, a plain command-line session and a headless server, and is
0007 % silenced during unit tests:
0008 %
0009 %   - 'gui'  : MATLAB waitbar (interactive desktop).
0010 %   - 'cli'  : animated command-line bar (interactive terminal).
0011 %   - 'log'  : plain milestone lines, e.g. "Running BLAST: 30%". Contains no
0012 %              control characters, so it stays readable in redirected logs
0013 %              and on headless / -batch servers.
0014 %   - 'none' : no output (during tests, or when disabled).
0015 %
0016 % The backend can be forced with setRavenProgress, e.g. setRavenProgress('log')
0017 % on a compute cluster, or setRavenProgress('off') to silence all progress
0018 % reporting.
0019 %
0020 % Usage
0021 % -----
0022 % For loops with one cheap-to-expensive iteration each, count one per pass:
0023 %
0024 %     PB = progressReport(N, 'Task name');   % before the loop
0025 %     for i = 1:N
0026 %         ...                                % loop body
0027 %         PB.count;                          % or count(PB), also in parfor

0029 %     PB.done;                               % optional; cleans up on early exit
0030 %
0031 % For very long loops over cheap iterations, set the absolute position at
